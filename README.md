# 📋 Projeto Lista de Tarefas (To-Do List)

Uma aplicação simples e eficiente para gerenciamento de tarefas, desenvolvida com foco em produtividade e organização do dia a dia.

## 🚀 Funcionalidades

### ➕ Adicionar tarefas

Permite criar novas tarefas de forma rápida e prática.

### ✏️ Editar tarefas

Possibilidade de atualizar o conteúdo de tarefas já existentes.

### ❌ Remover tarefas

Exclusão de tarefas que não são mais necessárias.

### 💾 Persistência de dados com Local Storage

As tarefas são armazenadas localmente no navegador, garantindo que os dados não sejam perdidos ao atualizar a página ou fechar o navegador.

## 🛠️ Tecnologias Utilizadas

### React

Biblioteca JavaScript para construção de interfaces dinâmicas e reativas.

### Tailwind CSS

Framework de estilização utilitária para criação rápida de layouts modernos e responsivos.

### Vite

Ferramenta de build rápida e leve, utilizada para desenvolvimento e empacotamento da aplicação.

## 💡 Como funciona

A aplicação permite ao usuário gerenciar suas tarefas diretamente na interface, com atualizações em tempo real. Todas as ações (criar, editar e deletar) são refletidas imediatamente na tela.

Os dados são armazenados utilizando o Local Storage, o que garante persistência mesmo após o recarregamento da página, sem a necessidade de backend.

## 📦 Instalação e execução

### Instale as dependências
```
npm install
```

### Execute o projeto
```
npm run dev
```
